# Практика — поликлиническая терапия

Тренажёр на 400 вопросов для телефона, iPad и компьютера.

Сайт: **https://kasparovgs.github.io/therapy-trainer/**

## Как заниматься

- **Обучение:** выберите диапазон, ответьте на вопрос и нажмите «Проверить ответ». Затем переходите к следующему.
- **Экзамен:** ответы проверяются после завершения. К выбранным вариантам можно возвращаться и менять их. Пропущенные вопросы попадут в список повторения.
- **Повторение ошибок:** вопросы, на которые в последний раз ответили неверно. Правильный ответ при повторении убирает вопрос из списка.
- **Продолжение занятия:** место остановки и ответы сохраняются автоматически. Кнопка «Продолжить» появляется на главной.
- **Перенос прогресса:** кнопка настроек справа вверху → «Сохранить прогресс в файл». На другом устройстве выберите «Загрузить прогресс из файла».

Вопросы и варианты **никогда не перемешиваются**. Нумерация соответствует PDF; в списке ошибок вопросы тоже идут по исходным номерам. Ограничения по времени нет.

В Safari на iPhone или iPad можно выбрать «Поделиться» → «На экран Домой».

## Где хранятся данные

Прогресс хранится в `localStorage` текущего браузера. Очистка данных сайта удалит его. На разных устройствах прогресс отдельный; для переноса используйте JSON-файл. Регистрация, серверная база данных, аналитика и внешние шрифты не используются. Для открытия сайта требуется интернет.

Репозиторий и банк вопросов публичны. Для прохождения теста аккаунт GitHub не нужен.

## Источник и проверка

Основной источник — предоставленный `not_marked.pdf`. Из него перенесены все 400 вопросов, варианты и таблица эталонных ответов. Содержимое не генерировалось.

Проверено автоматически:

- нумерация 1–400 без пропусков и повторов;
- от двух до семи вариантов в исходном порядке;
- наличие каждого эталонного ответа среди вариантов;
- совпадение двух таблиц ответов;
- совпадение всех 400 выделений в `Itogovoe_testirovanie_otmech.pdf` с ключом.

Версии PDF различаются: у №96 другая формулировка, у №374 — расшифровка сокращения. В обоих случаях использована версия **not_marked.pdf**. Удалены номера страниц и переносы строк, обозначения вариантов приведены к русским строчным буквам.

Исходные PDF остаются вне репозитория. Проверенный банк находится в `data/questions.json`; метаданные содержат контрольную версию и результаты сверки.

Для повторного извлечения нужны Python, `pypdf` и `pdfplumber`:

```bash
python scripts/extract_questions.py ../not_marked.pdf \
  --marked ../Itogovoe_testirovanie_otmech.pdf \
  --output data/questions.json
```

## Локальный запуск и проверки

Сборка и установка зависимостей для сайта не нужны. Весь интерфейс — HTML, CSS и JavaScript.

```bash
npm start
```

Откройте http://localhost:4173/therapy-trainer/. Сервер также проверяет работу с префиксом репозитория GitHub Pages.

Проверки банка, подсчёта баллов, восстановления прогресса и порядка вопросов (Node.js 18+):

```bash
npm test
```

Для проверки интерфейса используется отдельно установленный Playwright. `PLAYWRIGHT_MODULE_PATH` позволяет указать уже имеющийся модуль, `BROWSER_CHANNEL=msedge` — установленный Edge. Скриншоты и временные файлы попадают в игнорируемую `.artifacts/`.

```bash
npm run test:browser
```

## Публикация

В **Settings → Pages** выбраны **Deploy from a branch → main → /(root)**. Изменения публикуются после отправки в `main`. Файл `.nojekyll` отключает обработку сайта Jekyll. Домен настраивать не требуется.
